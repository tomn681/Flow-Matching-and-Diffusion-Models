# GenLib Documentation

GenLib is a modular research codebase for latent autoencoders, diffusion models,
flow-matching models, and related training/inference infrastructure.

## Scope

- Unified CLI via `python -m genlib`
- Config-driven model/training orchestration
- Registry-based extension points for models, noise, schedulers, samplers, and trainers
- Inference pipeline abstractions for sampling, encoding, decoding, and evaluation
